### Gemini

Here is how the components of an agentic harness map to the classic 7-layer OSI model, organizing them from foundational compute up to cognitive strategy and application interface.

**The Agentic "OSI" Stack**

| Layer | Agentic Equivalent | Scope & Function | Classical OSI Analogue |
|---|---|---|---|
| 7 | Agent / Harness | The user-facing persona, multi-agent orchestration, and top-level constraints. | Application: Interface for the end-user. |
| 6 | Plan | Dynamic goal decomposition, reflection, and strategy formulation. | Presentation: Translates abstract intent into executable architectures. |
| 5 | Task & Chain | Stateful, bounded workflows (DAGs, specific sub-routines). | Session: Maintains state and dialogue over a sequence of steps. |
| 4 | Step | The atomic action cycle (Thought → Action → Observation). | Transport: Ensures reliable execution of a single instruction. |
| 3 | Message | Token structuring, context windows, and role definitions (User/System). | Network: Routes raw information into semantic packets. |
| 2 | Inference | Forward passes, probability distributions, token generation. | Data Link: Node-to-node data transfer (bits to tokens). |
| 1 | API | Raw compute endpoints, GPU hardware, and network interfaces. | Physical: The physical medium and electrical signals. |

**Layer-by-Layer Breakdown**

**Layer 1: API (The Physical Layer)**
The foundational infrastructure. This layer consists of the raw hardware, model hosting environments, and network endpoints (REST, gRPC). It is completely agnostic to the agent's intent; it simply accepts network payloads and returns data.

**Layer 2: Inference (The Data Link Layer)**
The translation of inputs into model-specific processing. This layer handles tokenization, embedding generation, context window limits, and the actual forward pass through the neural network. It turns raw API requests into LLM tokens.

**Layer 3: Message (The Network Layer)**
Tokens are formatted into structured, semantic payloads. This is where ChatML, system prompts, and conversation histories operate. Just as IP routes packets, the message layer structures raw tokens into recognized roles (System, User, Assistant, Tool) that the model can interpret contextually.

**Layer 4: Step (The Transport Layer)**
The atomic unit of reliable execution. A single "step" represents one round-trip of reasoning: generating a response, parsing an intent (like a tool call), executing the tool, and returning the immediate observation. Like TCP ensuring a packet arrives, the step layer ensures a single prompt yields a parsed, executable action.

**Layer 5: Task & Chain (The Session Layer)**
Sequences of steps strung together to accomplish a bounded goal. This layer manages the state over time—such as a predefined workflow that retrieves documents, summarizes them, and drafts an email. It maintains the "session state" of a specific job until completion or failure.

**Layer 6: Plan (The Presentation Layer)**
The cognitive architecture layer. Rather than executing hardcoded chains, this layer dynamically decomposes high-level user goals into sub-tasks. It handles reflection, ReAct strategies, and error-correction. It translates and "presents" the abstract user intent down to Layer 5 as actionable tasks.

**Layer 7: Agent Harness (The Application Layer)**
The highest level of abstraction. This represents the autonomous agent or swarm of agents interacting directly with the user application, retaining long-term memory, adhering to safety guardrails, and managing persona.

**The Orthogonal Plane: Observability**

In classical networking, telemetry (like SNMP or flow logs) is not a layer; it is a management plane that cuts vertically across the entire stack. Observability functions exactly the same way in an agentic harness:

- At Layer 1/2, it tracks latency, TTFT (time to first token), and API costs.
- At Layer 3, it logs the raw prompt and completion strings.
- At Layer 4/5, it traces tool-call success rates and chain execution times.
- At Layer 6/7, it monitors semantic drift, plan completion, and user alignment.

**The OSI Model Is Broken — Layers 8 & 9**
This presentation discusses why the classic networking stack falls short for AI and proposes adding Layer 8 (Agent Communication) and Layer 9 (Agent Semantics) specifically for agent-to-agent interoperability.

**2. The Invisible Internal Stack (Autonomic Physiology)**

Inside the Cell, our earlier 6-layer stack runs continuously as background physics. The agent never "knows" it is moving between layers; the harness automatically warps compute and context around the active focus of attention.

**Automatic Model Tiering (Cognitive Metabolism)**

Instead of hardcoding `model="gpt-5"` or `model="claude-haiku"` onto specific nodes, the Cell dynamically shifts its underlying inference substrate (L1/L2) based on real-time cognitive demand:

- **Reflex Arcs (L3 Turns):** Routine parsing, schema formatting, file reading, and deterministic retries automatically route to ultra-fast, tiny models (or even pure deterministic code).
- **Deliberative Thought (L5 Planning):** When an effector port returns an unexpected error, ambiguity spikes, or a goal needs decomposition, the cell seamlessly upshifts the active trajectory into a frontier reasoning model.
- **Seamless Continuity:** Because the Cell maintains the semantic state across turns, the shift between models feels like a single continuous mind changing gears—moving from muscle memory to deep concentration.

**Context Folding (Perspective & Resolution Scaling)**

Rather than treating context as a flat, fixed-size array of messages that eventually overflows and crashes, the harness treats state like human visual perspective: near things are crisp and high-resolution; distant things compress into gist.

As execution flows up and down the internal layers, state automatically folds:

| Stack Horizon | Resolution | What Exists in Active Context |
|---|---|---|
| Active Turn (L3) | 100% Raw | Exact tool outputs, stack traces, file diffs, immediate dialogue. |
| Completed Trajectory (L4) | Folded (Tactical) | Raw tool chatter collapses into an outcome node ("Refactored auth.ts; 14 tests passing"). |
| Completed Task / Plan (L5) | Folded (Strategic) | Entire multi-step branches collapse into a single topological node on the cell's mental map. |
| Cross-Cell History (L6) | Folded (Episodic) | Distilled lessons, updated preferences, and artifact pointers stored via Mount Ports. |

**Reversible Unfolding:** Because every folded summary retains a cryptographic or structural pointer to its underlying trace, the Cell can "squint" at a distant memory—if a downstream bug implicates an earlier folded trajectory, the harness automatically unfolds that specific branch back into high resolution without bloating the rest of the context.

**The "Fabric of Reality" (Epistemic Transparency)**

Traditional harnesses leak their abstractions into the prompt ("System: You are in step 3 of 10. Remember to use JSON. Your context is 70% full.").

In a true Agent Cell, the harness never speaks to the agent. Instead:

- Connected Ports simply appear as natural physical affordances in the agent's environment (like hands and eyes).
- Constraints and Budgets feel like natural intuition or fatigue rather than rigid system rules.
- Sub-cells spawned via Effector Ports feel like delegating a thought to a colleague—the parent cell receives the clean result at its Receptor Port without ever polluting its own consciousness with the sub-cell's messy trial-and-error.

**3. How It Feels in Practice**

Imagine wiring a Codebase Migration Cell to a Human Intent Port:

- You drop a high-level goal into the Receptor Port: "Migrate our payment service from Stripe v11 to v14."
- **Unfolding & Planning (L5):** The Cell upshifts to a frontier reasoning model, inspects its codebase Mount Port, and internally spins up three ephemeral sub-cells (one for dependency analysis, one for code transforms, one for test verification) wired via temporary connectors.

- **Resolution:** The sub-cells dissolve, their folded outcomes merge into a single coherent pull request emitted through the parent Cell's Effector Port, and the entire Cell returns to a low-power resting state—having spent frontier compute only on the 5% of decisions that actually required deep thought.

**1. The Network & Overlay Physics**

**MAC Addressing & Heterogeneous Nodes**

Every node and port is minted with an immutable hardware-style identity (`mac://02:a1:...`) paired with semantic capabilities. Because the mesh treats all nodes uniformly at the transport boundary, the topology is completely agnostic to what powers a node's interior:

| Node Engine Type | Internal Execution | Example Role |
|---|---|---|
| `llm/cell` | Probabilistic inference + automatic model tiering & context folding | Autonomous operator, planner, negotiator |
| `logic/wasm` | Deterministic state machine, math, or rules engine | Double-entry ledger, tax calculator, timer |
| `io/hardware` | Physical driver / MQTT / GPIO bridge | Smart pitcher scale, card reader, thermometer |
| `human/bridge` | Mobile/web UI projecting living Markdown as interactive cards | Store owner, customer kiosk |

**Software-Defined Topology & Self-Discovery**

There is no static wiring diagram. Nodes broadcast Presence Beacons onto the GraphQL mesh advertising their MAC address, port schemas, and intent tags.

- **Autonomous Binding:** When a node requires a capability (e.g., `need: liquidity/ledger`), it queries the mesh (`_discover(capability: "ledger")`), negotiates a handshake, and instantiates a Connector Document between their respective ports.
- **GraphQL as the Nervous System:** The mesh layers a unified, federated GraphQL schema over all active documents:
  - `query`: Lazily resolves @mentions and traverses topological links on demand.
  - `mutation`: Applies atomic frontmatter patches or appends semantic state to a living surface.
  - `subscription`: Drives reactive execution—nodes sleep at zero compute until a subscribed frontmatter field or linked port mutates.

**2. Living Documents & Lazy Inheritance**

Configuration, runtime state, ports, connectors, and messages are ephemeral, in-memory living Markdown surfaces—never persisted to disk unless a storage mount explicitly subscribes to them.

- **YAML Frontmatter (The Physics):** Holds deterministic state, MAC addresses, schemas, permissions, and reactive bindings. Enforced directly by the runtime substrate.
- **Markdown Body (The Semantics):** Holds human- and LLM-legible context, intent, and live @mentions (`@mac://...` or `@port/name#field`). An @mention is a live GraphQL pointer, not static text.

**Lazy Context & State Inheritance**

Nodes sit inside topological scopes (StandScope ⊃ CounterScope ⊃ CashierCell). Rather than stuffing every ancestor rule into an agent's prompt, inheritance is lazy and copy-on-write:

- A child node's frontmatter declares `inherits: ["@mac://02:00:00:00:00:01"]`.
- In the agent's active context, inherited policies and world-state appear only as collapsed, low-token @mention anchors.
- When the agent's attention touches a domain (e.g., issuing a refund), the runtime intercepts the reference, resolves the ancestor's GraphQL subgraph, and unfolds only the relevant policy slice into the active turn. Once resolved, it folds back away.

**3. Policy Physics: Positive/Negative Models, Push-Down & Bubbling**

Governance is embedded directly into document frontmatter rather than coded into agent prompts:

- **Positive Permissions (`grant`):** Explicit capabilities and port-binding rights (e.g., `grant: ["port:kiosk.read", "connector:bind:supplier.*"]`).
- **Negative Permissions (`deny`):** Hard invariant boundaries enforced by the connector substrate before an effect can fire (e.g., `deny: ["ledger.debit > 20.00"]`).
- **Push-Down (Top-Down Cascade):** When a parent scope mutates a policy in its frontmatter, GraphQL subscriptions immediately push the new constraint down the inheritance tree. Every child node feels the new boundary on its very next turn without redeployment.
- **Bubbling (Bottom-Up Escalation):** When a node attempts an action blocked by a `deny` rule—or encounters an ambiguity outside its `grant` envelope—it does not throw a fatal error. The blocked intent wraps itself into a Bubble Signal and traverses up the topological parent chain until it reaches a node whose permissions encompass the action (e.g., a manager cell or a human bridge). That ancestor can sign a single-use capability lease, amend the policy, or reject it.

### Gemini

Traditional version control (like Git) is built for engineers manually staging static text diffs. A thinking machine does not "commit" files or "resolve merge conflicts"—it perceives, reflects, imagines counterfactuals, consolidates memories, and relives experience.

Instead of a repository of dead snapshots, persistence in an Agent Cell mesh is a **Mnemonic Continuum**: a content-addressed, bi-temporal causal graph where every living Markdown document leaves behind a continuous wake of **Moments**.

**1. The Vocabulary of Cognitive Continuity**

| Mechanical VCS | Mnemonic Continuum | How It Works Inside the Mesh |
|---|---|---|
| Commit | Moment (`moment://...`) | Crystallizes automatically at metabolic boundaries—whenever a node shifts its state, emits an effect, or absorbs a stimulus. |
| Repo / History | Stream (`stream://...`) | A continuous thread of lived causality (`stream://waking` vs. simulated counterfactuals). |
| Branch & Checkout | Daydream (`imagine://...`) | A zero-side-effect copy-on-write fork where a Cell tests risky actions against synthetic port mirrors before acting in reality. |
| Merge | Absorb / Evaporate | Insights from a successful daydream fold into waking reality; failed daydreams dissolve without polluting history. |
| Merge Conflict | Tension (`tension://...`) | Concurrent mutations spawn a living Tension document that wakes an arbiter node to harmonize the competing truths. |
| Squash / GC | Consolidation | During idle cycles, noisy micro-moments compress into high-level episodic memories while keeping cryptographic roots for unfolding. |
| Checkout / Replay | Reminisce / Relive | Reconstructs the exact world—and the exact epistemic slice the agent perceived—at any past Moment. |

**2. Core Mechanisms**

**Causal Provenance (Not Just What Changed, But Why)**

Every `moment://` node in the storage substrate is content-addressed and binds three things together:

- **The Delta:** The exact frontmatter physics patch and semantic body evolution.
- **The Trigger (`caused_by`):** Live @mention pointers to the upstream port events, subscriptions, or bubble signals that provoked the thought.
- **The Epistemic Horizon (`perceived`):** A bi-temporal record tracking both world-time (the true state of the mesh) and belief-time (the specific @mentions the Cell had actually unfolded into its context at that millisecond). Replay never cheats with hindsight.

**Daydreaming (`imagine://`)**

When an agent faces high stakes or ambiguity, it does not guess blindly in production. It opens an `imagine://` stream. The runtime clones the target nodes lazily in memory, swaps live Effector Ports for simulated sandboxes, and lets the Cell run forward. If the outcome respects all inherited `policy.deny` invariants, the Cell absorbs the resulting plan into `stream://waking`. If it hits a wall, the daydream evaporates.

**Tensions Over Conflicts**

Because frontmatter is structured physics and the body is living prose, concurrent edits rarely corrupt syntax—they create semantic divergence (e.g., StandOperator raises cup price to $5.00 at the exact millisecond OwnerPhone pushes down a $4.50 neighborhood cap). Instead of locking or throwing an error, the substrate materializes a living `tension://` surface linking both Moments, waking the node with highest scope authority to reconcile them.
