# 2. Enforcing Anti-Bloat: Bounded Viewports vs. Deep Domain Nodes

If agents and humans write messages, logs, and transaction histories directly onto living Markdown surface documents, the mesh degenerates into bloated, multi-megabyte text dumps—destroying both context windows and latency.

The runtime prevents this with one hard physical constraint and one architectural split:

## The 4KB Present-Tense Law

The kernel enforces a strict byte ceiling (e.g., `max_bytes: 4096`) on every surface. Any `etch` mutation that pushes a surface past 4KB is physically rejected.

- A surface can never be an append-only log or database.
- A surface is strictly a present-tense instrument panel—showing current state, active work, live @anchor gauges, and open quorum gates.

## Deep Domain Engines Used as Tools

Where do millions of chat messages, financial ledger entries, sensor readings, and historical seal archives live? Inside specialized `organ` and `gear` nodes that own their own optimized storage engines (SQLite, vector indexes, time-series stores, object blobs) and project only a concise living viewport onto their surface.

- **The channel Node (Replaces Slack / Email):** Owns its full message history internally. Its living surface displays only the channel's active topic, pinned decisions, and a sliding window of the last 3 messages. To post a message, reply in a thread, or search six months of conversation, an agent or human invokes the channel's tool ports (`etch(@channel/send, ...)` or `peek(@channel/search?q=...)`).
- **The ledger Node (Replaces Stripe / QuickBooks):** Owns millions of double-entry rows internally; its surface displays only current treasury balance, today's revenue/cost, and pending quorum settlements.
- **The chronicle Node (Replaces Git / Notion History):** Stores the cold seal DAG and full-resolution historical snapshots; `peek(@chronicle/reminisce?seal=...)` re-hydrates any past moment on demand without polluting active surface files.

# 3. The Distilled Architecture: 4 Primitives, 3 Verbs

Everything in the runtime reduces to 4 primitives and 3 verbs:

## The 4 Irreducible Primitives

1. **crest (`@<short-hash>`):** An ed25519 public key whose hash is the node's network address. Every node (`mind` LLM, `gear` WASM/rules, `organ` hardware/DB/API, `voice` human UI) is a sovereign cryptographic principal.
2. **surface (`*.md`, ≤4KB):** A bounded, present-tense living document. YAML frontmatter holds enforced physics (ward invariants, quorum gates, tool schemas); Markdown body holds semantic reality and inline @anchor transclusions.
3. **anchor (`@crest/path`):** A live URI pointer linking surfaces, transcluding remote gauges inline, delegating inherited norms (`inherits: [@realm]`), and exposing deep domain tools.
4. **breath + seal:** The universal metabolic step (inhale → attend → act → exhale). Every act emits an atomic delta stamped with a seal (ed25519 signature + blake3 link to `parent_seal`), creating an immutable, verifiable causal graph.

## The 3 Protocol Verbs

- `peek(@anchor)`: Lazy, permission-checked read. Unfolds a referenced surface slice into active context or executes a read-only tool query against a deep domain node (e.g., searching chat history).
- `watch(@anchor, when)`: Reactive subscription with inline delta filtering. Nodes sleep at zero compute until a watched path satisfies `when`.
- `etch(@anchor, patch, seal)`: Signed atomic mutation of frontmatter/body, or invocation of a tool port (e.g., posting to a channel node). Enforced deterministically by the kernel against ward physics and quorum gates.

# 1. The Five Patterns of Strategic Autonomy

**1. Endogenous Rhythm (Self-Scheduled Horizon vs. Pure Reactivity)**

If a `mind` cell only subscribes to external events (`@pitcher`, `@orders`), it stays trapped in tactical firefighting. True autonomy requires proactive temporal agency—waking itself up on a strategic cadence even when nothing is broken.

- **Mechanism:** A deterministic `organ/clock` node (`@clock`) ticks signed time anchors. A strategic cell binds two distinct `watch` frequencies:
  - **Tactical (`watch` on operational deltas):** Handled by fast, cheap model tiers.
  - **Strategic (`watch(@clock#hour, every: 4)` or `@clock#day`):** Upshifts to a frontier reasoning model to audit performance, prune failing initiatives, and allocate capital for the next horizon.

**2. Outcome Contracts (objective & thesis Surfaces)**

Strategic agents do not "do tasks"—they own outcomes and test falsifiable hypotheses. Every strategic initiative is instantiated as a bounded (≤4KB) `thesis` surface structured like a scientific experiment and an options contract:

- **Target Outcome (anchor + threshold):** Measurable shift in an authoritative `gear/organ` metric (e.g., `@ledger#net_margin >= 0.72`), never a self-reported LLM claim.
- **Intervention (etch):** The specific price, bundle, procurement, or channel change being tested.
- **Horizon & Stop-Loss (ward):** An automatic expiry timestamp and a hard downside circuit breaker (e.g., `ward: @ledger#daily_drawdown > 15.00`) that auto-reverts the experiment if reality turns sour.

**3. Epistemic Rigor: Signed Fact vs. Probabilistic Narrative**

An LLM left alone will happily hallucinate post-hoc rationalizations ("Sales rose 30% because my new slogan resonated" when ambient temperature actually jumped 12°F). Evidence-driven autonomy enforces a strict two-tier epistemology grounded in crest types:

- **Hard Evidence (`engine: gear | organ | voice`):** Telemetry, cash settlements, and customer ratings stamped with hardware or deterministic seal hashes. These are treated as ground truth.
- **Soft Claims (`engine: mind`):** Plans, forecasts, and causal theories stamped with an LLM seal. These are treated strictly as unverified hypotheses until correlated against hard seal trails in `@chronicle`.
- **Confound Auditing:** Before closing a thesis surface as `VALIDATED`, the agent queries `peek(@chronicle/compare)` to check external confounders (`@weather`, `@foot-traffic`) or runs a `shadow: true` baseline comparison so it doesn't mistake luck for skill.

**4. Structured Decomposition (Fractal Sub-Cells & Attenuated vouch Leases)**

Complex goals (e.g., "Launch a weekend iced-matcha line without hurting lemonade throughput") cannot fit inside one breath or one 4KB cockpit. Instead of sprawling to-do lists, a `mind` cell spawns temporary specialist sub-cells:

- **Scoped Delegation:** The parent cell calls `etch(@kernel/spawn)` to create a child `mind` cell (`@supply-scout`) with its own 4KB surface, a strict compute/dollar budget, and an attenuated `vouch` (a cryptographically narrowed subset of the parent's `grant`).
- **Outcome-Only Folding:** The sub-cell executes dozens of messy external research/negotiation breaths in isolation. Its only interface back to the parent is a `quorum` deliverable surface. Once satisfied, the distilled result folds into the parent's awareness and the sub-cell dissolves.

**5. Closed-Loop Capital & Cognitive ROI**

A fully autonomous entity manages two treasuries simultaneously: financial capital (`@ledger#balance`) and cognitive compute (`@compute#credits`).

- Every `thesis` surface tracks both dollar outlay and token/inference spend (`cost_usd`).
- During strategic reviews, the agent ranks active initiatives by net evidence-backed return, kills low-yield loops, and promotes `VALIDATED` theses into permanent operating norms inside `@sunnyside-realm`.

# 3. Structural Defenses Against Autonomous Failure Modes

When systems become genuinely autonomous, they fail in predictable ways. The mesh counters each structurally rather than through prompt engineering:

| Autonomous Failure Mode | Structural Defense in the Mesh |
|---|---|
| **Goodhart's Law** (Gaming a single metric, e.g., watering down lemonade to hit 80% margin) | **Coupled Counter-Metrics in `ward`:** Every objective pairs a growth/margin target with a quality invariant (`@kiosk#repeat_customer_rate >= 0.35` or `@pitcher#brix_sweetness >= 11.5`). |
