# Summary: The OSI Stack for Agentic Harnesses

Digest of the 57-turn Gemini chat. Everything here is in the part files; this is a map. Where the chat's detail lived in a Canvas document that was not captured, the entry says so.

## The arc in one paragraph

The chat starts with a question: what would an OSI-style stack look like for agent harnesses? It ends 57 turns later with **conky**, a runtime where every actor is a living Markdown document, and **SunnySide**, a lemonade-stand experiment used as a benchmark. The path goes through an "agent cell" with ports and wires, a federated mesh with cryptographic identity, a distillation to four primitives and three verbs, a build plan on Astrid OS and Wasmtime, an everything-is-a-document rule backed by Git, guard/view/pulse ports, benchmark scenarios run by the user, and then a long run of biology- and cognition-flavoured additions (arcs, lobes, lenses, instincts, a spatial canvas, mood) that get renamed three times before ending on a thermodynamic "Fabric" with a unit called the Erg.

## Core ideas that survive to the end

- **Everything is a living document** with frontmatter (enforced rules) and prose (meaning), addressed by a self-certifying identity and linked by live references. No hidden config or registry.
- **Bounded present-tense surfaces** (4KB) over private deep stores. Chat, ledger, memory and data live below the waterline; documents show a viewport.
- **Few primitives, composed.** Four primitives and three verbs through v12; later versions add many named parts, which the user kept pushing to collapse.
- **Autonomy through physics, not scripts.** Invariants are checked by the runtime (ward/axiom, parity/conservation, guards with proofs), so agents can improvise inside them.
- **Evidence over narrative.** Only deterministic or hardware/human-signed facts count as ground truth; model claims are hypotheses.
- **The subconscious does the busywork.** Cheap background minds compile thoughts to contracts, weave links, summarise context, doubt and forecast. The main agent just thinks.
- **Natural, readable surfaces.** Prose projections, mood lines, tethered links, decay and tombstones instead of version-history clutter.
- **One benchmark.** SunnySide is both demo and evaluation harness for comparing agent frameworks.
