# Thought to change

## Idea

Free-form thinking is turned into validated changes by a background process. The critique is that the thinker must be able to see and override the translation.

## Composes from

Writes checked by rules; [background minds](background-minds.md).

## Removes

Not yet worked out.

## Falsifying test

The translation changes a page in a way the thinker cannot see or override before it takes effect.
