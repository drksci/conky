**Counts**

**Method**
- Title and Paper link are copied from the source. The description column is the source's own first sentence, cut at about 80 characters. Where the cut is shown, it ends with "...".
- The "why" column is my note, at most 15 words. It is based on the description text, and for the Top 15 also on the bullet points.
- Skipped as out of scope: model architecture, training recipes, vision, speech, and domain-science papers with no bearing on the topics.
- Inclusion means the paper is on DAIR.AI's list and fits a topic tag. It does not mean DAIR.AI judged it relevant to this project.

## 3. Top 15 to read first

Ranked by fit to the project. Based on each source entry's full text, not the one-line description alone.

1. **JevAct** (Nov 2 - 8). Runtime gate checks policy and task completion before consequential tool writes, using code checks and a prefill-only decision model; reported Opus 4.6 success on tau2-bench Telecom rising from 39.5% to 80.7%. Idea: put deterministic checks between agent and tools, and ask the model only the questions the checks cannot settle.
2. **Auton Agentic AI Framework** (Mar 1 - 8). Separates a declarative agent spec (Cognitive Blueprint) from the runtime engine, for auditability and portability. Idea: the spec is a document and the runtime is the enforcer, the same split as this project.
3. **Runtime-Independent Persistent Agents** (Aug 31 - Sep 6). Identity, private memory and versioned code persist while model, harness and host are replaceable, via a six-step pause, save, validate, attach, load, resume handoff. Idea: a concrete test for resuming from stored documents, with the authors noting that behavioural continuity is a separate question.
4. **Filesystem Memory Audited** (Jul 27 - Aug 2). Agents keep memory as a directory of markdown files; organising the store roughly halves retrieval cost on large material, but answer quality stays flat. Idea: file-based memory is cheap to search, but the value of organising it needs measuring.
5. **AI-Native Design Docs** (Sep 7 - 13). The SMART library is a graph of natural-language design docs, and coding sub-agents regenerate the implementation from them on each version. Idea: documents as the source and code as a projection, close to this project's event-log model.
6. **Skills as Verifiable Artifacts** (May 4 - 10). Argues skills are untrusted until verified and the runtime should enforce that default, so human review fires only on unverified items. Idea: gate skill execution on verification, not on origin.
7. **GitSwarm** (Oct 12 - 18). Hundreds of asynchronous agents share one Git repository; each commit records which earlier commits it builds on, with no central planner. Idea: lineage-recording commits as a coordination substrate, similar to an append-only log.
8. **JevAgentHarness** (Oct 19 - 25). Routes routine tool choices to a decision model, used only above a confidence threshold fitted on the agent's own trajectories; the LLM decides below it. Idea: default to cheap decisions with a calibrated fallback; the source reports a 19.0-point loss when delegation has no fitted threshold.
9. **HarnessMM** (Oct 26 - Nov 1). Stores settled decisions as executable graphs and reuses them when tool receipts satisfy their guards; unsupported cases return to the model. Idea: skip model calls when state already determines the action.
10. **AgentBaton** (Oct 26 - Nov 1). Learns when to hand a long task once from an expensive model to a cheaper one; reports 65.9% lower API cost on average with largely preserved accuracy. Idea: a one-time handoff detector as a cost policy.
11. **WikiTrace** (Nov 9 - 15). Each lesson links to a diagnosis and to the raw trajectory, and agents follow those links when an insight is weak or conflicting. Idea: lessons carry provenance so they can be checked before use.
12. **ReHarness** (Oct 12 - 18). Adds backward revision: after each task, the finished trajectory rewrites the reflections that were retrieved for it. Idea: memory entries revised by outcome, not only appended.
13. **1,000 Synthetic Computers** (May 4 - 10). Pairs a user agent and a worker agent on realistic synthetic file systems for runs of over 8 hours and 2,000+ turns on average. Idea: a shared synthetic-organisation scenario for harness benchmarks.
14. **MerchantBench** (Aug 3 - 9). A 365-day order-level e-commerce simulation scored by cumulative net assets, where incoherence compounds; the best configuration reaches 27.3% of the human mean. Idea: a long-horizon coherence benchmark for organisation-level evaluation.
15. **OneManCompany** (Apr 26 - May 3). Replaces static org charts with portable agent identities hired per task from a talent market; reports 84.67% on PRDBench. Idea: organisation structure as runtime data, recruited dynamically rather than wired in advance.
