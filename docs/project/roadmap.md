# Roadmap

This page is the single tracker for work. Steps are listed in order, each with a stable id (a label, not a position) and a state: `done`, `next` or `later`. Exactly one step is `next`, which `scripts/check_docs.py` checks. What each planned capability would strain in today's code is listed in [seams](seams.md), so that a step is not built in a way that closes off a later one. A step is unbuilt unless it is `done`; [status](status.md) says what exists.

- R30 (done): Pay once: a content-addressed cache for model answers, keyed to the moment, outside the history, with modes `on`, `off`, `refresh` and `only` and a `conky cache` command. Tested with stand-in providers only. Decision: [0030](../decisions/0030-pay-once.md). Reference: [providers](../reference/providers.md#cache). Other costly work is audited in the decision, and the cache is built for model answers alone.
- R22 (next): Spaces hand down context and reactions as well as rules, and a page may join several spaces. Joining and leaving are ordinary writes to `within`, and a write that changes `within` is judged by the rules of the spaces before and after it ([decision 0022](../decisions/0022-leaving-a-space-is-a-write-the-space-can-refuse.md)). The leaving rule is built (R29, below); context is built for rules, watch conditions and `set` values (not embeds), while reactions and several spaces are not. Replaces the cascading-context step. Ideas: [inheritance](../ideas/inheritance.md), [cascading-context](../ideas/cascading-context.md). Difference: a rule can speak about the situation a page is in, so a limit can depend on context the page did not write; no compared harness evaluates a constraint outside the model. Shown by playbooks, then by a character-written rule that a hostile model cannot break.
- R23 (later): Seeds, faces and a self for every page: a fixed phrase per identifiable page, a stable identifier and a monochrome face drawn from it, and [taste as a page](../ideas/house-style.md). Ideas: [seeds-and-faces](../ideas/seeds-and-faces.md), [character](../ideas/character.md). Decision: [0017](../decisions/0017-derived-data.md).
- R12 (later): The clock: time passes as an ordinary write to a clock page. Idea: [clock](../ideas/clock.md).
- R17 (later): Budgets for model pages and the first background mind: budgeted model pages that doubt, wonder, tidy and orient. Ideas: [background-minds](../ideas/background-minds.md), [model-pages](../ideas/model-pages.md). Depends on R4 and R12.
- R3 (later): Staleness and relief: something that acts on pressure from size or age (split, summarise or archive). Ideas: [staleness](../ideas/staleness.md), [measures](../ideas/measures.md). Essay: [pressure-not-walls](../essays/pressure-not-walls.md).
- R24 (later): Several pages changed in one commit, with rules that can see the whole group. Git can commit several files atomically, but a conky write changes one page, and no rule evaluates a group. Idea: [patterns](../ideas/patterns.md). Decision: [0002](../decisions/0002-git-is-the-store.md).
- R14 (later): Rules that can see who signed a change, with approvals and the gatekeeper. Ideas: [approvals](../ideas/approvals.md), [gatekeeper](../ideas/gatekeeper.md). Decision: [0009](../decisions/0009-patterns-not-features.md).
- R13 (later): Dry run: ask what a change would do on a throwaway branch of the history. Idea: [dry-run](../ideas/dry-run.md). Decision: [0002](../decisions/0002-git-is-the-store.md).
- R15 (later): Rename with link repair: one change that also rewrites every link and embed. Idea: [rename](../ideas/rename.md).
- R1 (later): Tables as Parquet beside their page, with large data by pointer. Idea: [tables](../ideas/tables.md). Decisions: [0010](../decisions/0010-no-debt-no-down-migrations.md), [0003](../decisions/0003-data-beside-pages.md).
- R11 (later): Derived data: trace summaries and the people's view. That is summaries per page and period, links from a fact to the change that set it, and a generated index for a notes application. Ideas: [trace](../ideas/trace.md), [obsidian-view](../ideas/obsidian-view.md), [connectors](../ideas/connectors.md). Decision: [0017](../decisions/0017-derived-data.md).
- R11a (later): The screen, step 1: a text outline of a vault. Every step of the screen is derived data, can be deleted and has a golden test. Decision: [0025](../decisions/0025-the-screen-is-built-in-small-steps.md).
- R11b (later): The screen, step 2: the same outline as A2UI messages for one surface. Idea: [a2ui](../ideas/a2ui.md).
- R11c (later): The screen, step 3: one static page that renders those messages, with no server. The Rust core may begin after this step.
- R11d (later): The screen, step 4: updates as the history grows.
- R11e (later): The screen, step 5: the activity strip, from the record's trailers.
- R11f (later): The screen, step 6: a prompt button that makes an ordinary write.
- R11g (later): The screen, step 7: the compositor, which thinks once about layout and then keeps up by reflex, as the outward [codec](../ideas/codec.md). Idea: [compositor](../ideas/compositor.md).
- R6 (later): The pattern maker, which turns goldens into patterns, each a space (double-entry accounts as the first thing it is asked to produce). A pattern starts private to the space that made it and rises one space at a time by use, which also depends on R12, R14, R17 and R22. Idea: [patterns](../ideas/patterns.md). Decisions: [0009](../decisions/0009-patterns-not-features.md), [0023](../decisions/0023-a-pattern-starts-private-and-rises-by-use.md), [0002](../decisions/0002-git-is-the-store.md).
- R18 (later): Direction and drift: read a page's activity against a goal page. Idea: [direction-and-drift](../ideas/direction-and-drift.md). Related: [arcs](../ideas/arcs.md).
- R28 (later): One step at a time: hold a vault, run one due reaction, stop on a breakpoint expression, and branch from any event, with stepping and free running giving the same history. Needs the reaction order stated in the reference. Idea: [stepping](../ideas/stepping.md). Related: [dry-run](../ideas/dry-run.md), [clock](../ideas/clock.md).
- R27 (later): The exploratory trail trial: a party plays a text Oregon Trail through the terminal connector, run by Conky and by one plain single-loop baseline on the same model and budget, with raw traces kept. Not a benchmark result. A second form stops the party mid-trail and hands the vault to a fresh consumer. Needs R26. Plan: [evaluation plan](../research/evaluation-plan.md). Decision: [0025](../decisions/0025-the-screen-is-built-in-small-steps.md).
- R7 (later): The model-backed resume test, scoring behavioural continuity apart from state continuity. The mechanical form is done as R21. Idea: [assimilation-test](../ideas/assimilation-test.md). Decision: [0014](../decisions/0014-benchmark-shape.md).
- R8 (later): The harness-neutral benchmark against other agent harnesses. Decisions: [0013](../decisions/0013-evidence-not-scripts.md), [0014](../decisions/0014-benchmark-shape.md).
- R25 (later): Connectors for the protocols people already use: small processes beside a vault that present it in a protocol's terms and turn what arrives into ordinary signed writes. The terminal connector is built (`conky connect terminal`, see [connectors](../reference/connectors.md)); the protocol connectors are not. The codec at a connector reads and writes through a [codec](../ideas/codec.md). Idea: [connectors](../ideas/connectors.md). Research: [protocols](../research/protocols.md).
- R19 (later): The Rust core and the browser. Decision: [0012](../decisions/0012-rust-core-planned.md).
- R10 (later): How two vaults relate: a space becomes its own vault when its vault grows too large or too busy, and the two stay linked. Idea: [vault-splitting](../ideas/vault-splitting.md). Decision: [0002](../decisions/0002-git-is-the-store.md).
- R2 (done): First slice of measures as self-watches, with pressure as the first use. Idea: [measures](../ideas/measures.md). Decision: [0008](../decisions/0008-measures-are-self-watches.md). Related: [0006](../decisions/0006-size-is-a-rule.md).
- R4 (done): Model pages and provider pages: a page that asks a question state cannot answer, with the provider named by a page. Tested against stand-in servers, not a live provider. Idea: [model-pages](../ideas/model-pages.md). Decisions: [0007](../decisions/0007-inference-for-real-thinking.md), [0019](../decisions/0019-providers-are-pages.md). Related: [learned-reactions](../ideas/learned-reactions.md).
- R26 (done): A model with nothing to configure: command providers and detection. A provider that runs a program already on the machine, and a fixed order that picks a provider when a vault names none. Decision: [0024](../decisions/0024-a-model-is-reached-by-a-key-or-a-local-program.md). Related: [0019](../decisions/0019-providers-are-pages.md).
- R31 (later): Where a value came from: rules that can tell what a page wrote from what arrived from outside, so nothing read becomes a rule or a habit unchecked. Idea: [provenance](../ideas/provenance.md).
- R32 (later): Keys that change hands: retiring and revoking a signer without breaking the history behind it, each event judged by the signers in force when it was made. Idea: [keys](../ideas/keys.md).
- R33 (later): Several writers at once: a write held under a lock, and two processes that write one vault settling who goes first. Idea: [writers](../ideas/writers.md).
- R34 (later): Which model answers is a page: the order providers are tried in, and the guard for each, as data a character can change. Idea: [model-choice](../ideas/model-choice.md).
- R35 (later): A page that reviews: a second reading of an answer before it is kept, as an ordinary page with a verdict a rule can see. Idea: [reviewer](../ideas/reviewer.md).
- R36 (later): Text as it arrives: an answer that streams, with the record still one write when it settles. Idea: [streaming](../ideas/streaming.md).
- R37 (later): Reading the field: outside writing brought in on a schedule, distilled and shared, under a stated budget. Idea: [outside-reading](../ideas/outside-reading.md).
- R29 (done): A character writes pages: an `ask` entry with `writes` takes an answer that is pages, each an ordinary write by the asker into a named space, inside limits the runtime enforces, with the leaving rule of decision 0022. Tested with stand-in models only. Decision: [0028](../decisions/0028-a-character-writes-pages.md). Ideas: [thought to change](../ideas/thought-to-change.md), [inheritance](../ideas/inheritance.md). Reference: [rules and reactions](../reference/rules-and-reactions.md#an-answer-that-is-pages).
- R20 (done): `conky demo`, a narrated example vault built with the real write path. See [status](status.md).
- R21 (done): `conky assimilate`, the mechanical form of the resume test: take over a stopped vault from its folder, check it and carry on, with no model. Idea: [assimilation-test](../ideas/assimilation-test.md). See [status](status.md).
