# Roadmap

Ordered next steps. Each is unbuilt; see [status](status.md) for what exists.

1. Tables as Parquet beside their page. Idea: [tables](../ideas/tables.md). Decision: [0009](../decisions/0009-no-debt-no-down-migrations.md).
2. Measures, starting with pressure. Idea: [measures](../ideas/measures.md). Related: [0006](../decisions/0006-size-is-a-rule.md).
3. Model-backed pages: a page that asks a question state cannot answer. Decision: [0008](../decisions/0008-inference-for-real-thinking.md). Idea: [learned-reactions](../ideas/learned-reactions.md).
4. Grouped writes: several pages changed together, all or nothing, with rules that see the group. Idea: [patterns](../ideas/patterns.md).
5. A pattern library, with double-entry accounts as the first pattern. Idea: [patterns](../ideas/patterns.md). Decision: [0018](../decisions/0018-patterns-not-features.md).
6. The assimilation test. Idea: [assimilation-test](../ideas/assimilation-test.md). Decision: [0011](../decisions/0011-benchmark-shape.md).
7. The harness-neutral benchmark against other agent harnesses. Decisions: [0010](../decisions/0010-evidence-not-scripts.md), [0011](../decisions/0011-benchmark-shape.md).
8. Fold further ideas one mechanism at a time, by the rungs in [0012](../decisions/0012-archive-and-rungs.md).
